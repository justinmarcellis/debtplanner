Here is the one picture I would like you both to keep. Claude Code is an agent: software that takes a goal, works out the steps and carries them out, using a Claude model to do the reasoning [CLM-001]. It runs inside your engineers’ own environment: their terminal, their editor, the repository, their tests and git, and other tools you connect. It works in a loop. One, it understands: it reads the code and the ticket. Two, it plans: it can show you the plan before it changes anything. Three, it acts with your tools: it edits files and runs commands such as your test suite. Four, it verifies: it runs the tests, reads the results and fixes what failed, then goes round again until the task is done [CLM-003]. CTO, the check in front of step three is the part for you. Your administrators choose how that check works: ask the engineer before every edit or command, or Auto mode, where a separate model reviews each action; and they can switch the riskier modes off centrally [CLM-606]. Either way, engineers review every change before it merges. (80 seconds)
