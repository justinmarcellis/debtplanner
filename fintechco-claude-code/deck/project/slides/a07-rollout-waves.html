rollout/rollout-plan.md · wave sizes are planning assumptions

If asked how the rollout works: after the week-nine decision, four two-week waves take you from the thirty pilot users to all 180 by May seventh. Every wave includes all three teams, so each team’s tooling problems surface early while the group is small; squads with the most regulated code paths go last. Each wave has entry prerequisites and an exit review before the next starts, and if the decision is to extend the pilot, every date moves by the same number of weeks.
