If asked what is behind the ROI: these six assumptions, each with three values. Loaded cost is an assumption to replace with your HR figure. Hours saved is also an assumption: the base four hours is ten percent of a week, set below the field-experiment results [CLM-623]; one trial found experienced developers slower [CLM-650], so if the pilot measures less than one to two hours, the week-nine gate says stop. Usage cost uses Anthropic’s published enterprise range [CLM-619]. The pilot replaces every assumption with a measured number, and the calculator lets your finance team change any of them.
