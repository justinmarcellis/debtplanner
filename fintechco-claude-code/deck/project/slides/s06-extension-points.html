Five extension points make the agent yours without changing how engineers work. CLAUDE.md is a plain text file in the repository with your team’s rules, for example never log full card numbers; the agent reads it at the start of every session [CLM-007]. It guides; the next ones enforce. MCP, the Model Context Protocol, is an open standard for connecting the agent to other tools and data, such as a ticket tracker [CLM-006]. Hooks are your own scripts that run automatically before or after the agent uses a tool, and a hook can block the action outright [CLM-010]. Subagents are specialist helpers that work on parts of a task in parallel, such as a security reviewer [CLM-008]. And claude -p runs the same agent from a script or a CI pipeline with no one typing [CLM-005]. You will see four of these in the demo. First, why this matters for FinTechCo. (65 seconds)
